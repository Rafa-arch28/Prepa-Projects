GUIA RAPIDA: ARCHIVOS .TXT EN C++
=================================

Esta guia muestra como crear, escribir, agregar y leer archivos de texto.


1. LIBRERIAS NECESARIAS
-----------------------

#include <fstream>   // Permite trabajar con archivos.
#include <iostream>  // Permite usar cout y endl.
#include <string>    // Permite usar string y getline.

using namespace std;


2. TIPOS DE FLUJO
-----------------

ofstream: abrir un archivo para escribir.
ifstream: abrir un archivo para leer.
fstream: abrir un archivo para leer y escribir.


3. CREAR Y ESCRIBIR UN ARCHIVO
------------------------------

Este programa crea "datos.txt". Si el archivo ya existe, borra su contenido
anterior y escribe desde el principio.

#include <iostream>
#include <fstream>

using namespace std;

int main()
{
    ofstream archivo("datos.txt");

    if (!archivo)
    {
        cout << "No se pudo crear el archivo." << endl;
        return 1;
    }

    archivo << "Primera linea." << endl;
    archivo << "Segunda linea." << endl;

    archivo.close();

    return 0;
}


4. AGREGAR INFORMACION SIN BORRAR LO ANTERIOR
----------------------------------------------

El modo ios::app agrega el contenido al final del archivo.

#include <fstream>

using namespace std;

int main()
{
    ofstream archivo("datos.txt", ios::app);

    if (!archivo)
    {
        return 1;
    }

    archivo << "Esta linea se agrego al final." << endl;

    archivo.close();

    return 0;
}


5. LEER UN ARCHIVO LINEA POR LINEA
----------------------------------

ifstream se usa para leer. getline permite leer una linea completa,
incluyendo los espacios.

#include <iostream>
#include <fstream>
#include <string>

using namespace std;

int main()
{
    ifstream archivo("datos.txt");

    if (!archivo)
    {
        cout << "No se pudo abrir el archivo." << endl;
        return 1;
    }

    string linea;

    while (getline(archivo, linea))
    {
        cout << linea << endl;
    }

    archivo.close();

    return 0;
}


6. LEER DATOS SEPARADOS POR ESPACIOS
-------------------------------------

Si "datos.txt" contiene:

Juan 18
Ana 20
Luis 19

Se puede leer cada dato con el operador >>:

#include <iostream>
#include <fstream>
#include <string>

using namespace std;

int main()
{
    ifstream archivo("datos.txt");

    string nombre;
    int edad;

    if (!archivo)
    {
        cout << "No se pudo abrir el archivo." << endl;
        return 1;
    }

    while (archivo >> nombre >> edad)
    {
        cout << "Nombre: " << nombre << endl;
        cout << "Edad: " << edad << endl;
    }

    archivo.close();

    return 0;
}


7. LEER Y ESCRIBIR CON FSTREAM
------------------------------

fstream permite usar el mismo objeto para leer y escribir.

#include <iostream>
#include <fstream>

using namespace std;

int main()
{
    fstream archivo("datos.txt", ios::in | ios::out | ios::app);

    if (!archivo)
    {
        cout << "No se pudo abrir el archivo." << endl;
        return 1;
    }

    archivo << "Nueva linea." << endl;

    archivo.close();

    return 0;
}


8. MODOS IMPORTANTES
--------------------

ios::in       Abrir para leer.
ios::out      Abrir para escribir.
ios::app      Agregar siempre al final.
ios::trunc    Borrar el contenido anterior al abrir.
ios::binary   Abrir en modo binario.

Se pueden combinar usando |, por ejemplo:

fstream archivo("datos.txt", ios::in | ios::out | ios::app);


9. RUTAS DE LOS ARCHIVOS
------------------------

Si solo escribes el nombre:

ofstream archivo("datos.txt");

El archivo se busca o se crea en la carpeta desde donde se ejecuta
el programa, que no siempre es la misma carpeta donde esta el codigo.

Tambien puedes usar una ruta relativa:

ofstream archivo("Trabajo Diario/datos.txt");

O una ruta absoluta, aunque normalmente es mejor evitarla:

ofstream archivo("C:/Users/TuNombre/Documents/datos.txt");


10. RECOMENDACIONES
-------------------

1. Siempre verifica si el archivo se abrio correctamente.
2. Usa close() cuando termines de trabajar con el archivo.
3. Usa getline para leer lineas completas con espacios.
4. Usa >> para leer datos separados por espacios.
5. Recuerda que ofstream escribe e ifstream lee.
6. Para agregar sin borrar, usa ios::app.
7. En C++, el modo correcto es ios::app, con dos puntos.


ESTRUCTURA GENERAL
-------------------

ofstream archivo("nombre.txt");       // Escribir
ifstream archivo("nombre.txt");       // Leer
fstream archivo("nombre.txt");        // Leer y escribir

archivo << "Texto";                   // Escribir
getline(archivo, linea);              // Leer una linea
archivo.close();                      // Cerrar
